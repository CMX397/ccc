# 动漫短剧项目

这是我的原创动漫短剧项目仓库，主要用于整理短剧策划、角色设定、脚本、分镜、素材需求和制作计划。

## 项目定位

项目方向是：

- 竖屏动漫短剧
- 搞笑沙雕日常
- 合租群像喜剧
- 适合短视频平台持续连载

一句话概括：

`一个只想安静活着的社恐合租青年，被两个离谱室友逼到每天社死。`

## 当前内容

这个仓库将逐步整理以下内容：

- 项目策划案
- 制作执行计划
- 单集脚本
- 分镜模板
- 角色资产说明
- 样片测试清单
